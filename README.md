# 体感俄罗斯方块

只用 **笔记本摄像头 + 浏览器**，就能把俄罗斯方块玩成体感游戏。

项目基于浏览器端 **MediaPipe Pose**，实时识别 **33 个人体关键点**，并把动作映射成俄罗斯方块操作：

- 左手抬高：方块左移
- 右手抬高：方块右移
- 双手高举：旋转方块
- 双手下压：加速下落

## 技术栈

- Vite
- 原生 HTML / CSS / JavaScript
- MediaPipe Tasks Vision（浏览器端姿态识别）

## 本地运行

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址，通常是：

`http://localhost:5173`

## 使用方式

1. 允许浏览器访问摄像头。
2. 站在画面中间，确保上半身完整出现在镜头里。
3. **双手高举约 0.8 秒** 开始游戏。
4. 按照页面下方动作提示操控方块。

## 交互说明

为了避免误触，项目内置了简单的手势冷却与状态判断：

- 横向移动和旋转有短冷却时间，避免连发过快。
- 双手下压会持续触发软降落。
- 游戏结束后，再次双手高举即可重新开始。

## 兼容建议

建议使用以下浏览器：

- Chrome
- Edge

并确保：

- 页面运行在本地开发服务器或静态服务器下
- 摄像头权限已开启
- 房间光线充足，人物和背景有一定对比度
